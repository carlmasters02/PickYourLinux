    Linux in two minutes

    Linux is the core, not the whole thing

    Linux is a kernel: the part of an operating system that talks to your hardware. Linus Torvalds started it in 1991, and it's free and open source, so anyone can use it, study it and build on it. It already runs most of the world's servers, every Android phone and the Steam Deck.

    A distro makes it usable

    On its own, a kernel isn't something you can sit down and use. A distribution, or distro, wraps it in everything else: a desktop, apps, a way to install software, and decisions about how it all fits together. Ubuntu, Fedora and Linux Mint are all distros. They run the same kinds of apps, but they look, feel and update differently.

    Most distros are built on another one

    Because Linux is open, anyone can take an existing distro and change it. That's how most distros began: as Debian, Fedora or Arch with different choices on top. So they form a family tree, and where a distro sits in it tells you a lot about how it will behave day to day.

    Three roots, and a few loners

    A distro's family decides a lot about daily life: which package manager you use, which guides apply to you, and how quickly new software arrives.

    Try a distro without installing it

    Almost every distro can run straight from a USB stick, so you can test it on your own computer before changing anything.

    1. Pick a distro

      Take the quiz or browse the catalog, then download the ISO file from the distro's official site.

    2. Write it to a USB stick

      Use Fedora Media Writer, balenaEtcher or Ventoy. Ventoy lets you keep several ISOs on one stick. Writing erases whatever is on the stick.

    3. Boot it live

      Restart, open your PC's boot menu (often F12, F10 or Esc) and choose the USB. Nothing is installed until you run the installer.
